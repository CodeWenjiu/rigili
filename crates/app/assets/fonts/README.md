# LXGW Neo XiHei

Bundled UI font for Rigili.

- Source: <https://github.com/lxgw/LxgwNeoXiHei>
- Version: 1.306 (nixpkgs package `lxgw-neoxihei`)
- License: IPA Font License v1.0; see `LICENSE-LXGWNeoXiHei.md` and `LICENSE_CHS.md`
- Loaded at startup by `platform::load_ui_font`; the theme selects it through
  `theme.font_family`.
